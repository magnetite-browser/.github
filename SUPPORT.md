# Support

- Bugs and feature requests: open an issue in the repository they concern,
  usually [magnetite](https://github.com/magnetite-browser/magnetite/issues).
- Questions: [GitHub Discussions](https://github.com/orgs/magnetite-browser/discussions) or [support@magnetitebrowser.org](mailto:support@magnetitebrowser.org).
- Security issues: see [SECURITY.md](SECURITY.md). Never in a public issue.

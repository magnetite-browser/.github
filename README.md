# .github

Organisation-wide files for [magnetite-browser](https://github.com/magnetite-browser).

- `profile/README.md`: the text shown on the organisation page.
- `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md`: defaults that GitHub applies
  to every repository in the organisation that does not carry its own copy.

The browser repository carries its own `SECURITY.md` and `CODE_OF_CONDUCT.md`,
which win over the defaults here; keep them in sync when the policy changes.
The other repositories use the defaults.
